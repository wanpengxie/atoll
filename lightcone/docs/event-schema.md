# Coagent JSON Lines Event Schema

Critical server, daemon, and agent transitions are emitted as one JSON object per stdout line.

Required fields:

- `ts`: ISO-8601 timestamp generated by the emitting process
- `event`: event name such as `channel.start`, `message.deliver`, or `agent.status`

Common optional fields:

- `channel_id`
- `message_id`
- `machine_id`
- `server_id`
- `request_id`
- `session_id`
- `pid`

`type` is reserved for stream/protocol payloads and must not be used as the JSON Lines event name.
